## Editor + Terminal

- [Visual Studio Code](https://code.visualstudio.com/) as my main driver when I'm editing for a while (i.e., project-based work). For the configuration, you can take a look at my various settings and extensions that keep me productive.

- [Neovim](https://neovim.io/) for when I want to quickly edit when I'm bouncing around in the terminal. For the configuration, you can take a look at my [dotfiles for neovim](https://github.com/kevinjalbert/dotfiles/tree/master/.config/nvim).

- [iTerm2](https://iterm2.com/) for my terminal.

- [Zsh](http://zsh.sourceforge.net/) for my shell. For the configurations, you can look at my [.zshrc](https://github.com/kevinjalbert/dotfiles/blob/master/.zshrc) and [.zaliases](https://github.com/kevinjalbert/dotfiles/blob/master/.zaliases) files.

- [Tomorrow](https://github.com/chriskempson/tomorrow-theme#tomorrow) as my colour scheme where I can get it to work.

- [FiraCode](https://github.com/tonsky/FiraCode) for my font choice (has nice ligatures).

## Applications

### Productivity

- [Notion](https://www.notion.so/) has been a great all-purpose tool that I've adopted. I use it throughout my day to record/perform many functions including note-taking, project planning, and knowledge management.

- Time tracking applications help me better understand my mobile and laptop usage. Overall I like to see where my time is going so that I have a better grasp of where I can make improvements.

### Development

- [TablePlus](https://tableplus.io/) is a GUI-based multi-purpose database management tool (i.e., MySQL, SQLite, PostgreSQL, etc.). I used to use a specific GUI application for different databases, but this bundles them all into one clean GUI.

- [SourceTree](https://www.sourcetreeapp.com/) is my preferred GUI tool for working with `git` repositories. I personally do a lot of my work in the terminal, although I do like it for managing staging hunks of a file.

- [Dash](https://kapeli.com/dash) is a powerful programming documentation lookup tool. It has great integrations with other applications as well.

### Utilities

- [Alfred](https://www.alfredapp.com/) is my replacement for Spotlight. It is customizable and powerful. I have the Powerpack which allows me to use workflows.

- System monitoring tools provide me with finer-grain detail over my system with respect to CPU/Memory/Network/SSD/Battery.

- Menu bar management applications clean up my menu bar on macOS so that I only have frequently used/looked at applications visible.

- [BetterSnapTool](https://apps.apple.com/app/bettersnaptool/id417375580) gives me customizable keystrokes for moving my windows around on my desktop.

- Screenshot and screen recording tools for quickly sharing images, videos and GIFs. They also have expressive annotation tools built in.

- [1Password](https://1password.com/) has been an application that my family and I have been using for a while. It excels at password management and security concerns.

### Communication

- Email clients that offer a unified inbox and customizable swipe actions for managing both work and personal email.

- [Slack](https://slack.com/) is the de facto communication tool for work.

- [Discord](https://discordapp.com/) is a great application that I use for persisted chatroom conversations with my family. I also use it for voice conversations when gaming.

- Various messaging apps for communication with family and friends across different platforms.
